# Friction Intelligence Engine (FIE) Specifications

The Friction Intelligence Engine is the core behavioral intervention layer of Study Friction AI. It combines heuristic analysis, real-time metrics, and Large Language Model (Gemini) reasoning to mitigate addictive scrolling behaviors.

## 1. Brainrot Scoring Algorithm
The engine calculates a "Brainrot Score" ($S$) for every active session on supported platforms (Instagram Reels, YouTube Shorts, TikTok, etc.).

$$S = (R^{1.2} \times 5) + \min(\frac{T}{30}, 40)$$

Where:
- **$R$**: Number of reels/shorts consumed in the current session.
- **$T$**: Total time spent in the session (seconds).

### Dynamic Multipliers
- **Velocity Multiplier (1.3x)**: Applied if Reels Per Minute (RPM) > 6.
- **Circadian Penalty (1.2x)**: Applied during "High-Risk Hours" (22:00 – 04:00).

## 2. Friction Levels & Interventions
Interventions scale based on the Brainrot Score and User Profile.

| Level | Intensity | Scroll Delay | Intervention Mechanism |
| :--- | :--- | :--- | :--- |
| **1** | Gentle | 300ms | 15% Grayscale + Slight scroll resistance |
| **2** | Moderate | 800ms | 30% Grayscale + Intent Check Popup |
| **3** | Strong | 1.5s | 50% Grayscale + Warning Overlay |
| **4** | Aggressive | 3.0s | 70% Grayscale + 3min Mandatory Cooldown |
| **5** | Maximum | 10.0s | 95% Grayscale + 10min Lockdown + Scroll Disable |

## 3. Loophole Prevention (Technical Hardening)
The content script (`friction.js`) implements several low-level blocks to ensure interventions cannot be bypassed:
- **Navigation Blocking**: Intercepts and cancels `ArrowUp`, `ArrowDown`, `Space`, `PageUp`, `PageDown`, `Home`, and `End` keys.
- **Scrollbar Removal**: Sets `overflow: hidden` on `<html>` and `<body>` during Level 5 lockdowns.
- **Conscious Preview**: Scrapes metadata of the *next* video and displays it during the scroll delay to break the "surprise-reward" loop of the algorithm.
- **Persistence**: Uses a `MutationObserver` to prevent websites or users from deleting the intervention overlays via DevTools.

---

## 4. AI Intelligence Engine
When a Gemini API key is configured, the system elevates from heuristics to reasoning:
- **Dynamic Decisioning**: Metrics are sent to the LLM to decide the friction level based on intent.
- **Adaptive Coaching**: Generates context-aware "shaming" or "encouraging" messages based on the current `tone` preference (Strict, Balanced, or Chill).
- **Behavioral Profiling**: Analyzes multi-session data to assign a user archetype:
    - **Dopamine Chaser**: High-frequency, high-velocity scrolling.
    - **Night Owl Scroller**: Intense sessions during sleep hours.
    - **Work Procrastinator**: Chronic micro-distractions during work hours.
